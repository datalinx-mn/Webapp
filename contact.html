Техникийн дэмжлэг хүсэхдээ

  • Төхөөрөмж болон browser: Android Chrome, iPhone Safari, Windows Chrome гэх мэт;
  • Асуудал гарсан ойролцоо огноо, цаг;
  • Нууц мэдээлэлгүй screenshot эсвэл screen recording.

Нууц үг болон мэдээллийн аюулгүй байдал

Дэмжлэг авахдаа нууц үг, session token, API credential, банкны нууц мэдээлэл, service-account key болон хэрэглэгчийн хувийн мэдээллийг чат, comment эсвэл public сувгаар илгээхгүй. DataLinx дэмжлэг нь хэрэглэгчийн нууц үгийг бүтнээр нь асуух шаардлагагүй.

Тохиргоо болон дата шилжүүлэлт

Одоогийн Excel эсвэл Google Sheets файлаас бараа, харилцагч, эхний үлдэгдэл шилжүүлэх бол баганын нэр, нэгж, код, үнэ болон үлдэгдлийн жишээ бүтэц илгээнэ. Хувийн болон бизнесийн нууц дата агуулсан файлыг зөвхөн тохирсон, хамгаалагдсан сувгаар хуваалцана.

Хамтын ажиллагаа болон сурталчилгаа

DataLinx-ийн public хуудас эсвэл Free апп дотор ивээн тэтгэсэн мэдээлэл байрлуулах сонирхолтой байгууллага сурталчилгааны гарчиг, тайлбар, зураг, холбоос, хугацаа болон зорилтот байрлалаа явуулж болно. Зар нь хэрэглэгчийн үндсэн ажлыг хаахгүй, төөрөгдүүлсэн товч хэлбэртэй байхгүй бөгөөд бизнесийн дотоод датагаар targeting хийхгүй.
